# StudakPL

## Довідка студента для роботи в Польщі.

Оформлення документів, що підтверджують статус студента для роботи в Польщі.

### Документи

- Довідка з українського університету + переклад на польську
- Довідка з поліцеальної школи + за потреби легітимація
- Довідка з польського університету + за потреби легітимація

### Сайт

https://annetcccc.github.io/studakpl/

### Мови

Сайт доступний українською, російською та іспанською мовами.
